## 1. Мета роботи

Сформувати початкові навички роботи зі змінними та базовими типами даних Python: навчитися вводити дані з клавіатури, перетворювати текстові значення на числа, складати арифметичні й логічні вирази та виводити результати у зрозумілому форматі.

---

## 2. Постановка задачі

**Вхідні дані:** загальна тривалість у секундах.

**Потрібно:**
* Ввести кількість секунд як `int`;
* За допомогою операторів `//` і `%` визначити кількість повних годин, хвилин та секунд;
* Перевірити, чи перевищує загальна тривалість одну годину (3600 секунд).

---

## 3. Хід виконання

1. Значення тривалості зчитується з клавіатури функцією `input()` і одразу перетворюється на ціле число функцією `int()`.
2. Кількість повних годин обчислюється цілочисельним діленням `total_seconds // 3600`.
3. Кількість повних хвилин обчислюється так: спочатку береться залишок секунд після відрахування годин (`total_seconds % 3600`), а потім цей залишок ділиться націло на 60.
4. Кількість секунд, що залишилися, обчислюється операцією `total_seconds % 60`.
5. Виконується логічне порівняння `total_seconds > 3600`, результат якого має тип `bool`.
6. Усі результати виводяться на екран за допомогою функції `print()` та f-рядків.

---

## 4. Код програми

```python
# Практична робота 1. Варіант 7. Поділ часу

# 1. Введення загальної тривалості у секундах (перетворення str -> int)
total_seconds = int(input("Введіть загальну тривалість у секундах: "))

# 2. Обчислення кількості повних годин, хвилин та секунд
hours = total_seconds // 3600
minutes = (total_seconds % 3600) // 60
seconds = total_seconds % 60

# 3. Перевірка, чи перевищує тривалість одну годину (1 година = 3600 секунд)
is_more_than_hour = total_seconds > 3600

# 4. Виведення початкових даних і результатів
print(f"Загальна тривалість: {total_seconds} с")
print(f"Години: {hours}")
print(f"Хвилини: {minutes}")
print(f"Секунди: {seconds}")
print(f"Тривалість більша за одну годину: {is_more_than_hour}")
